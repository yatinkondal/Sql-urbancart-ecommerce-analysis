# Urban Cart – E-commerce Data Analysis Using SQL

## Project Overview

This project focuses on analyzing an e-commerce retail database using SQL and MySQL. It demonstrates how structured data can be queried to answer business-related questions and understand customer, product, order, and payment information.

## Project Objective

The main objective is to practice SQL concepts and use them to solve practical business problems in an e-commerce environment.

## Tools & Technologies

* MySQL 8.0
* MySQL Workbench
* SQL

## Database Structure

The project uses six related tables:

| Table           | Description                                    |
| --------------- | ---------------------------------------------- |
| Customers       | Stores customer information                    |
| Products        | Contains product details, prices, and stock    |
| Orders          | Stores customer order information              |
| Order_Items     | Contains products and quantities within orders |
| Payments        | Stores payment details                         |
| Product_Reviews | Contains customer reviews and ratings          |
